# 📱 ProEstoque - App Mobile

Este é o aplicativo móvel do **ProEstoque**, desenvolvido com **React Native** e **Expo** (Expo Router).

Para ver a documentação completa do projeto (incluindo Backend, Banco de Dados e Endpoints da API), acesse o [README principal do projeto](../README.md).

## 🚀 Como Executar o App

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Configuração do `.env`:
   Crie ou edite o arquivo `.env` com a URL da API backend:
   ```env
   EXPO_PUBLIC_API_URL=http://<SEU_IP_LOCAL>:3333/api
   ```

3. Inicie o servidor do Expo:
   ```bash
   npx expo start
   ```

4. Abra no seu dispositivo físico via **Expo Go** (escanear QR Code) ou pressione:
   - `a` para abrir no Emulador Android
   - `i` para abrir no Simulador iOS
   - `w` para rodar na Web
